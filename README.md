**SnapBunny — One‑Click Screenshot, Focused & Efficient**

Since I couldn’t find a good alternative to Steam’s instant screenshot feature, I went ahead and used AI to develop a lightweight screenshot tool myself: 截图兔 (SnapBunny).

SnapBunny is a one‑click screenshot tool built specifically for game developers, film creators, and reference material collectors. With a single keystroke, you can instantly capture your full screen or active window — whether you're playing a game outside Steam, watching a movie, or binging a TV series. It’s the perfect companion for saving visual references anytime, anywhere.

**Key features at a glance**

1.Window capture & full‑screen hotkey screenshots

2.Customizable hotkey combinations

3.Customizable save folder location

4.Screenshot sound effects + visual flash feedback

5.Customizable filename prefix

6.Start on boot & multi‑language interface

7.Thumbnail preview and management

**Why no more mode?**
Excellent tools like WeChat, ShareX, Snipaste, and PinPin already excel at region capture. SnapBunny stays lightweight and purpose‑built — we focus on doing “one‑click full‑screen/window capture” right, without feature bloat.
If you have great ideas, feel free to leave a comment — we’re always listening and iterating!

## SnapBunny Eagle v3 — Release Notes
- **Added Eagle integration**: Select Eagle as your image manager to capture screenshots with a shortcut and save them directly to a chosen folder for easy organization.
- **Added custom capture regions**: Drag to select an area or manually adjust its coordinates, width, and height. Save the region for repeated captures.
- **Added library detection and switching**: Automatically detect the current Eagle library and display its full path. Switch between recent libraries or browse to another library.
- **Added folder search and refresh**: Search by folder name or full path, browse nested folders, and refresh to discover newly created folders.
- **Added a dedicated Eagle shortcut**: Configure the Eagle capture shortcut independently from the local capture shortcut.
- **Improved capture mode switching**: Enabling Eagle pauses local capture. Disabling Eagle restores your original local save location and shortcut.
- **Improved language and theme support**: The Eagle Capture Assistant follows SnapBunny’s Chinese/English language setting and light/dark theme.
- **Added import failure protection**: Failed or unconfirmed imports display an error and retain the screenshot for review and manual import.
