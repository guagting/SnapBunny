# SnapBunny
截图兔，专为游戏影视创作者打造。一键截全屏或窗口，自定义热键、路径、文件名、提示音与闪屏、开机自启、多语言、缩略图。无区域截图，轻量专注。欢迎反馈。SnapBunny is a one-click screenshot tool for game and film creators. Capture full screen or active window with one key. Customizable hotkey, save path, filename, sound &amp; flash, auto-start, multi-language, thumbnail. No region selection, stays lightweight. Feedback welcome.
